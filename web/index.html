              Browser notifications

              Opt in for this Home in this browser. Push notifications use a generic message; open the signed-in website to review. Delivery depends on your browser, network and system settings.

              Enable on each phone or browser that should receive alerts. Only new alerts created after subscribing are eligible. An alert shown here or marked as viewed does not prove a push notification reached a phone. If alerts do not arrive, ask the Home manager to check notification setup.

              Camera calibration

              On the monitoring laptop, use Camera setup [C] in the live monitoring window. After moving or rotating the camera, invalidate the old view with R and recalibrate. Only confirm an unchanged view with B / Enter. Calibration cannot be changed remotely here.
